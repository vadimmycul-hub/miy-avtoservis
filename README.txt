РОЗГОРТАННЯ:
Завантажте ВСІ файли цієї папки до кореня GitHub-репозиторію.
Потім у Settings → Pages виберіть Deploy from a branch, branch main,
folder /(root), Save. Дочекайтеся публікації HTTPS-посилання.

ВСТАНОВЛЕННЯ НА iPHONE:
Відкрийте HTTPS-посилання у Safari → Поділитися → На початковий екран.

ВАЖЛИВО:
Дані зберігаються локально в браузері цього пристрою. Вони не синхронізуються
між пристроями. Регулярно створюйте резервну копію через вкладку «Резервна копія».
Не завантажуйте клієнтські дані до GitHub.
